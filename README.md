deskripsi:
Le Velours adalah website e-commerce sederhana yang menampilkan dan menjual produk kecantikan lokal. Website ini dirancang agar pengguna dapat melihat katalog produk, detail produk, menambahkan ke keranjang, melakukan checkout, serta melihat riwayat pesanan dengan tampilan yang menarik dan interaktif

daftar fitur:
1. Halaman beranda dengan hero dan slider brand
2. Katalog produk dengan filter brand
3. Halaman detail produk
4. Keranjang belanja
5. Checkout pesanan
6. Riwayat pesanan
7. Login dan register sederhana
8. Popup notifikasi dan interaksi UI
9. Halaman About Us dan Contact

teknologi yang di gunakan:
1. HTML
2. CSS
3. Framework boostrap
4. Javascript
